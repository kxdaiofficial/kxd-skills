# สกิล vector-redraw (KXD.ai #53) · ใช้กับ Claude Code

ให้ AI วาดรูป PNG/JPG ใหม่เป็นเวกเตอร์**ทีละเส้น** ไม่ใช่ auto-trace
วิธีคือ วัด → วาดเส้นให้พอดี → ตรวจ: AI เลือกทุกจุดเองจากภาพซูมที่มีตาราง โค้ดช่วยวัดและคำนวณความโค้ง แล้วเทียบผลกับต้นฉบับด้วยตัวเลข
ได้ไฟล์ SVG ที่แยกกลุ่มตามส่วน ทุก path มีชื่อ ไม่มีภาพ bitmap ติดไป เปิดแก้ต่อใน Illustrator, Figma, Affinity หรือ Inkscape ได้

## ต้องมี
- Claude Code
- Python 3 กับ numpy, opencv-python, pillow (`python3 -m pip install -r kit/requirements.txt`)
- ไม่ต้องมีแอปวาดรูปตอนทำงาน (ใช้ตอนเปิดไฟล์ผลลัพธ์เท่านั้น)

## ติดตั้ง (ครั้งเดียว)
1. ก๊อปทั้งโฟลเดอร์นี้ (`SKILL.md`, `kit/`, `scripts/`) ไปไว้ที่ `~/.claude/skills/vector-redraw/`
   (Windows: `%USERPROFILE%\.claude\skills\vector-redraw\`)
2. ลง Python library: `python3 -m pip install -r ~/.claude/skills/vector-redraw/kit/requirements.txt`
3. เปิด Claude Code ใหม่

## ใช้
1. เปิด Claude Code ในโฟลเดอร์ที่จะเก็บงาน แล้ววางรูปต้นฉบับขนาดเต็มไว้ในนั้น (ไม่ใช่ภาพแคปจอ ไม่ใช่ภาพย่อ)
2. พิมพ์ "ทำรูปนี้เป็น vector ให้หน่อย" แล้วบอกชื่อไฟล์
3. AI สร้างโฟลเดอร์งาน แบ่งภาพเป็นส่วนๆ (หลัง → หน้า) แล้วโชว์รายการให้ดูก่อน
4. 1–2 ส่วนแรก มันจะวาดแล้วหยุดให้ดูผลกับตัวเลขก่อน ตอบ OK แล้วมันทำส่วนที่เหลือต่อ
5. ได้ `redraw.svg` ในโฟลเดอร์งาน พร้อมรายงานว่าต่างจากต้นฉบับเท่าไหร่ และตั้งใจไม่วาดอะไร (เช่น gradient)

## ควรรู้
- ช้ากว่า auto-trace มาก เพราะวาดทีละส่วนและตรวจทุกส่วน (เทสหัวคนขนาด 160 px ใช้ราว 20 นาที ภาพฉากหลายคนนานกว่านั้นมาก) และกิน token
- ใช้ภาพขนาดเต็ม ยิ่งเล็กยิ่งยาก: ส่วนจิ๋วอย่างตากับปากในภาพเล็กอาจไม่ผ่านเกณฑ์ ต้องแก้เองต่อในแอป
- เหมาะกับภาพสีเรียบ เส้นชัด (flat illustration, ตัวละคร, ไอคอน) ภาพถ่ายหรือภาพที่มี gradient เยอะไม่เหมาะ
- ผลลัพธ์ทำมาเพื่อใช้งาน Visual Design / UI จริง: layer แยกแก้ได้ทีละส่วน เปลี่ยนสีให้เข้ากับแบรนด์ได้
