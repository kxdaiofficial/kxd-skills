# Vector redraw (วัด → วาดเส้นให้พอดี → ตรวจ)

สกิลนี้**วาดใหม่** ไม่ได้ trace: คุณ (AI) เลือกทุกจุดเองจากตารางตัวเลขและภาพซูมที่มีตาราง โค้ดแค่วัดตามเส้นนำที่คุณวาง แล้วคำนวณความโค้งให้ จากนั้นตรวจด้วยตัวเลขเทียบกับต้นฉบับ

## 🔴 กฎข้อเดียวที่ห้ามแหก
**ห้าม trace ทุกรูปแบบ** ห้ามใช้ Image Trace ของ Illustrator, Trace Bitmap ของ Inkscape, potrace, vtracer, `cv2.findContours`, เว็บแปลง vector อัตโนมัติ, โมเดลที่ "gen SVG ให้" (มันวาดรูปใหม่ ไม่ได้วาดตามรูปนี้) และ pipeline ที่ให้โค้ดตัดสินรูปทรงจากพิกเซลเอง (แบ่งสีด้วย k-means แล้วหาเส้นขอบ ก็ยังนับเป็น trace)
โค้ด**วัด**ได้ และ**คำนวณ** handle ได้ แต่ไม่เคยเป็นคนตัดสินว่ารูปทรงหรือจุดอยู่ตรงไหน
ถ้าผู้ใช้สั่งให้ใช้ tracer ให้บอกหนึ่งครั้งว่าสกิลนี้วาดใหม่ทีละเส้น แล้วถามก่อนทำอย่างอื่น

## ขั้นที่ 1: เช็กเครื่อง
- `python3 -c "import numpy, cv2, PIL"` ถ้าไม่ผ่าน ให้บอกผู้ใช้รัน `python3 -m pip install -r <โฟลเดอร์สกิลนี้>/kit/requirements.txt` (ขออนุญาตก่อนติดตั้งเอง)
- ไม่ต้องมีแอปวาดรูปเปิดอยู่ ผลลัพธ์เป็นไฟล์ SVG ผู้ใช้เปิดต่อใน Illustrator, Figma, Affinity หรือ Inkscape ได้

## ขั้นที่ 2: สร้างโฟลเดอร์งาน
```bash
bash <โฟลเดอร์สกิลนี้>/scripts/new-job.sh "<รูปต้นฉบับ>" <ชื่องาน> [โฟลเดอร์แม่]
```
- โฟลเดอร์สกิลนี้ปกติคือ `~/.claude/skills/vector-redraw` · โฟลเดอร์แม่ไม่ใส่ = โฟลเดอร์ที่เปิด Claude Code อยู่
- ต้นฉบับต้องเป็น**ไฟล์ขนาดเต็ม** ไม่ใช่ภาพแคปจอหรือภาพที่ย่อแล้ว สคริปต์แปลงเป็น `source.png` โดยไม่ย่อ และเขียนขนาดลง `progress.md`
- งานที่ค้างอยู่: ข้ามขั้นนี้ เข้าโฟลเดอร์งานนั้นแล้วอ่าน `progress.md` ก่อน
- ทุกคำสั่งหลังจากนี้รันจาก**ในโฟลเดอร์งาน**

## ขั้นที่ 3: อ่านกฎของงาน แล้วแบ่งส่วน
อ่าน `AGENTS.md` (วิธีทั้งหมด: กฎ, ลูปต่อส่วน, gate 1–3, รูปแบบรายงาน, บทเรียน) และ `TOOLS.md` (คำสั่งทุกตัวในหน้าเดียว **ห้ามเปิดไฟล์ใน `tools/`**) แล้ว:
- ดูภาพรวมครั้งเดียว `python3 tools/zoom.py 0 0 <W> <H> --overview`
- แบ่งภาพเป็นส่วนๆ เรียง**หลัง → หน้า** พร้อมกรอบพิกัด เขียนลง `progress.md` และชื่อ section ลง `sections/ZORDER.txt`
- **โชว์รายการให้ผู้ใช้ดูก่อนเริ่มวาด**

## ขั้นที่ 4: วาดทีละส่วน
**ประหยัด token:** ตัวเลขก่อน ภาพเฉพาะจุดที่ตัวเลขชี้ ทุกภาพที่เปิดค้างใน context และถูกคิดซ้ำทุกขั้นต่อจากนั้น
- 1–2 ส่วนแรกทำกับผู้ใช้ทีละส่วนตามลูปใน AGENTS.md: พิกัดจากตัวเลข (`runs.py`, `lmap.py`) + ซูมเล็กเฉพาะมุมและรอยต่อ (กรอบ ≤ 64 px ที่ 8×) → เขียน part script จาก `parts/_template.py` → Gate 1 overlay → Gate 2 fit (max ≤ 1.0 px, mean ≤ 0.4, handle ไม่เสีย) → render → Gate 3 (`verify.py` p95 ≤ 1.0 px แล้วดู `-look.png` จากนั้น `hotspots.py --box` หาของที่ลืม) → รายงาน → **หยุดรอผู้ใช้ OK**
- แก้ด้วยการย้ายหรือเพิ่มจุด ไม่ใช่ดัด handle เอง · ไม่เกิน 3 เวอร์ชันต่อส่วน เกินนั้นหยุดแล้วรายงานพร้อมตัวเลข
- สีต้อง sample จากภาพ (`h.colour(box)`) ห้ามพิมพ์ hex เอง · พิกัดต้องมาจากตาราง ภาพซูม หรือการวัด ห้ามเดาจากความจำหรือภาพย่อ
- ห้ามติ๊ก ✅ ส่วนที่ยังไม่ได้เปิดดูที่ ≥ 100 % เทียบต้นฉบับ ให้เขียนว่า "ยังไม่ได้ดูที่ 100 %"
- ผู้ใช้ OK สไตล์แล้ว ส่วนที่เหลือทำต่อทีละส่วนโดยไม่ต้องหยุดรอ แล้วให้ผู้ใช้ดูทีเดียวตอนจบ (เว้นแต่ผู้ใช้ขอดูทุกส่วน)
- ภาพใหญ่หลายคน ถ้าเครื่องมือรองรับ subagent: แยก agent ละหนึ่งส่วนได้ แต่ทุกตัวใช้ `sections/ZORDER.txt` ไฟล์เดียวกัน และเขียนเฉพาะไฟล์ของส่วนตัวเอง

## ขั้นที่ 5: ปิดงาน
- เช็กทั้งภาพ: `tools/render.py checks/final.png --all` → `tools/hotspots.py checks/final.png` (ค่าต่างเฉลี่ย, p95, สัดส่วนพิกเซลที่ต่างเกิน 60, จุดที่ต้องดู) → เปิด `-hot.png` → ดูทั้งภาพที่ 100 % เทียบต้นฉบับหนึ่งครั้ง บอกว่าตั้งใจไม่วาดอะไร (gradient, แก้มแดง, texture)
- `bash scripts/export-svg.sh redraw.svg` ได้ SVG ไฟล์เดียว แยกกลุ่มตามส่วน ทุก path มีชื่อ ไม่มี bitmap
- ถ้าผู้ใช้ export ต่อเป็น .ai / .eps จากแอปของเขา ให้เตือนเช็กว่าไม่มีภาพฝังติดไป
- บอกผู้ใช้ว่าไฟล์พร้อมใช้งาน Visual Design / UI: แต่ละส่วนเป็น layer แยก แก้ได้ เปลี่ยนสีให้เข้ากับแบรนด์ได้

ไม่เริ่มใหม่ ไม่แตะส่วนที่เขาไม่ได้พูดถึง หาให้เจอว่าตรงไหน (ถาม หรือ `hotspots.py` บน render ล่าสุด) หาสาเหตุที่วัดได้ (จุด, sample ที่โดนเส้นอื่นกวน, เส้นที่ขาด, ลำดับชั้น, สี) แก้เฉพาะตรงนั้น รัน gate 1–3 ใหม่ แล้วบอกว่าแก้อะไร
