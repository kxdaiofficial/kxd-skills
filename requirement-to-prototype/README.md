# Prompt: requirement → prototype

**ทำอะไร:** เอาเอกสาร requirement จาก PO กับ mockup คร่าวๆ ให้ AI แตกเป็นข้อๆ (มีเลข R) ลิสต์คำถามถึง PO แล้วสร้าง prototype โค้ดที่กดตาม flow ได้จริงทุกหน้า
**ใช้กับ:** Claude Code (หรือ AI agent ตัวอื่นที่เขียนไฟล์และรันคำสั่งในเครื่องได้) ต้องมี Node.js
**ในคลิป:** เอกสาร 1 หน้า + mockup วาดมือ 3 จอ ใช้เวลา 6 นาที 14 วิ ได้ R 26 ข้อ คำถามถึง PO 17 ข้อ codebase 11 ไฟล์ build ผ่าน

## วิธีใช้

1. สร้างโฟลเดอร์ใหม่ ใส่ไฟล์ requirement (PDF / Word / ข้อความ) กับรูป mockup ไว้ข้างใน
2. เปิด Claude Code ที่โฟลเดอร์นั้น
3. ลากไฟล์ทั้งหมดเข้าช่องแชต แล้ววาง prompt ข้างล่าง
4. รอจนเสร็จ แล้วพิมพ์ `เปิด dev server ให้หน่อย` เปิดลิงก์ localhost ใน Chrome โหมดมือถือ (DevTools → เลือก iPhone)

อยากลองก่อน ใช้ไฟล์ตัวอย่างในโฟลเดอร์ [`example/`](example/) ได้เลย (แอปสั่งกาแฟล่วงหน้า สมมติขึ้นมา)

## Prompt (ก๊อปทั้งกล่อง)

```
อ่าน requirement กับ mockup ที่แนบมาให้ครบทุกบรรทัด แล้วทำตามนี้ทีละขั้น

1. แปลง requirement เป็น requirement.md ใส่เลข R1, R2, ... ทุกข้อ
   แยกหัวข้อ "คำถามถึง PO" สำหรับจุดที่ไม่ชัดหรือขัดกัน ห้ามเดาเอง
   ถ้าต้องสมมติเพื่อทำต่อ ให้เขียนไว้ใน "สิ่งที่สมมติไว้"
2. สร้าง prototype ด้วย Vite + React + TypeScript + Tailwind
   (ถ้าโปรเจกต์มี Design System อยู่แล้ว ให้ใช้ component และ token ของมัน ห้ามวาดเอง)
   - ทำครบทุกหน้าใน mockup กดตาม flow ได้จริง ราคา/สถานะเปลี่ยนตามที่เลือกจริง
   - ใช้ข้อมูลตัวอย่างที่สมจริง ไม่ใช่ lorem ipsum
   - ทำทุก state ที่ requirement พูดถึง (ว่าง, หมด, เกินจำนวน, ฯลฯ)
   - ขนาดมือถือ 390 px
3. รัน npm run build ให้ผ่าน
4. สรุปท้ายเป็นตาราง: R แต่ละข้อ → อยู่หน้าไหน → ทำแล้ว/ยังไม่ทำ
   และลิสต์คำถามถึง PO อีกครั้ง
```

## ก่อนเอาไปโชว์

- เปิดกดไล่ flow เองสักรอบ AI build ผ่านไม่ได้แปลว่าหน้าตาถูกทุกจุด
- อ่าน "คำถามถึง PO" กับ "สิ่งที่สมมติไว้" ก่อน แล้วค่อยคุยกับ PO ทีละข้อ
- เวลาที่ใช้ขึ้นกับขนาด requirement และ model ที่ใช้ ของในคลิปเป็นงาน 3 หน้า
