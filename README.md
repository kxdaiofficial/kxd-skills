# KXD.ai Skills

Skill ฟรีสำหรับ UX/UI designer ที่อยากใช้ AI ทำงานจริง แจกจากคลิปของ KXD.ai

| Skill | ทำอะไร | ใช้กับ |
|---|---|---|
| [requirement-to-markdown](requirement-to-markdown/) | แปลงเอกสาร requirement ทั้งไฟล์เป็น Markdown ที่ AI อ่านง่าย ทุกข้อมีเลข R | claude.ai หรือ ChatGPT (แผนฟรีก็ได้) |
| [design-to-code](design-to-code/) | แปลงดีไซน์ใน Figma เป็น prototype โค้ดที่กดตามโฟลว์ได้ | Claude Code + Figma MCP |
| [wireframe-plan](wireframe-plan/) | อ่าน requirement ทั้งไฟล์ แตกเป็น flow / step / จอ แล้วออกแผนภาพ flow กับคำถามถึง PO ก่อนลงมือวาด wireframe | Claude Code |
| [prototype-brief-lite](prototype-brief-lite/) | พิมพ์ประโยคเดียว ได้ brief หน้าจอเต็ม: โครงจอ state ทุกแบบ ข้อมูลตัวอย่าง flow และคำถามถึง PO | claude.ai หรือ ChatGPT |
| [design-audit](design-audit/) | เปิดไฟล์ Figma จริง เทียบกับ requirement แล้วออกรายงานว่าครบไหม ขาด state ไหน ใช้ component จาก Design System ไหม | Claude Code + Figma MCP |
| [prototype-qa](prototype-qa/) | ตรวจ prototype ที่เป็นโค้ดเทียบกับ Figma: วัดค่าจริงทีละจุด กด flow จริง เช็คว่าใช้ Design System จริงไหม แล้วออกรายงาน defect (ไม่แก้ให้) | Claude Code + Figma MCP |
| [vector-redraw](vector-redraw/) | วาดรูป PNG/JPG ใหม่เป็นเวกเตอร์ทีละเส้น (ไม่ใช่ auto-trace) ได้ SVG ที่แยก layer ทุก path มีชื่อ เอาไปแก้และเปลี่ยนสีต่อใน Figma / Illustrator ได้ | Claude Code + Python 3 |
