# KXD.ai Skills

Skill ฟรีสำหรับ UX/UI designer ที่อยากใช้ AI ทำงานจริง แจกจากคลิปของ KXD.ai

| Skill | ทำอะไร | ใช้กับ |
|---|---|---|
| [requirement-to-markdown](requirement-to-markdown/) | แปลงเอกสาร requirement ทั้งไฟล์เป็น Markdown ที่ AI อ่านง่าย ทุกข้อมีเลข R | claude.ai หรือ ChatGPT (แผนฟรีก็ได้) |
| [design-to-code](design-to-code/) | แปลงดีไซน์ใน Figma เป็น prototype โค้ดที่กดตามโฟลว์ได้ | Claude Code + Figma MCP |
